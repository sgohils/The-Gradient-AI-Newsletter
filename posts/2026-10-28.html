Skill Dreaming: Evolving Repository Skills through Pull Request Streams


What happened: Researchers propose treating the stream of pull requests (PRs) as a living knowledge base for Large Language Model (LLM) agents. By mining PR diffs, comments, and merge histories, AI agents can automatically generate, adapt, and retire reusable repository‑specific skills.


Why it matters: As software projects evolve, static skill libraries quickly become obsolete. Leveraging PRs lets AI agents stay in sync with changing code structures, conventions, and maintenance practices, boosting reliability for complex engineering tasks such as automated code review, bug fixing, and feature implementation.


Key stats: The study examined thousands of PRs across several open‑source repositories, demonstrating that skill extraction from PR streams improves task success rates by up to 23 % compared to static skill sets.


Source: https://arxiv.org/abs/2610.36188

MARQ: A Modular, LLM-Agnostic Requirement Quality Assessor Infused with Systems Engineering Knowledge


What happened: Researchers unveiled MARQ, a plug‑in style assessor that enriches off‑the‑shelf LLMs with curated systems‑engineering knowledge, delivering consistent, criterion‑wide quality checks for software and hardware requirements.


Why it matters: Flawed requirements ripple through the development pipeline, inflating costs and delays. By bridging the gap between generic LLMs and domain‑specific engineering insight, MARQ promises faster, more accurate defect detection without retraining each model.


Key stats: • MARQ caught 85% of expert‑identified defects, versus 60% for vanilla LLMs. • Performance variance across runs dropped 30%, delivering steadier results. • The architecture works with multiple LLMs (GPT‑4, Llama 2, Claude) with no model‑specific tuning.
