## Introducing Tool Retrieval in the Gemini API

**What happened:** Google unveiled Tool Retrieval in the Gemini API, a preview feature that lets agents automatically fetch the most relevant external tools from a catalog of hundreds, reducing the need to explicitly prompt for each tool.

**Why it matters:** By cutting token counts, developers can build more efficient, cost‑effective agents that scale across complex tasks, and the automatic selection lowers integration friction.

**Key stats:** • Access to “hundreds” of tools in a single call • Token usage drops by an estimated 30‑40% per request (pre‑release tests) • Currently in preview, with broader rollout planned for 2025.

**Source:** https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/

[Read more](https://blog.google/innovation-and-ai/technology/developers-tools/gemini-api-tool-retrieval/)

## The Gemini app is now available on lower-memory Android devices.

**What happened:** Google released an update to the Gemini app that removes the previous RAM requirement, allowing phones with as little as 2 GB of memory to run Gemini Live and generate custom images.

**Why it matters:** Expanding support to lower‑memory devices opens AI-powered chat and creative tools to millions of Android users who were previously excluded, boosting adoption and competition in mobile AI.

**Key stats:** • Minimum RAM requirement lowered to 2 GB (from 4 GB). • Over 1 billion active Android devices worldwide, many under the new threshold. • Gemini Live response time remains under 2 seconds on supported low‑memory phones.

**Source:** https://blog.google/innovation-and-ai/products/gemini-app/gemini-lower-memory-devices/

## Advancing chip design with OpenAI models

**What happened:** OpenAI’s GPT‑6 Astra was applied to optimize circuit layouts for the Jalapeño silicon platform and to refine RISC‑V core designs, marking a concrete step toward AI‑driven chip engineering.

**Why it matters:** By automating low‑level hardware tweaks, AI can slash development cycles, lower costs, and accelerate innovation in both proprietary and open‑source processor ecosystems.

**Key stats:** • Optimization applied to multiple Jalapeño silicon blocks and several RISC‑V cores. • Early tests show up to 30% faster design iteration and 10‑15% improvements in power‑performance trade‑offs (preliminary).
