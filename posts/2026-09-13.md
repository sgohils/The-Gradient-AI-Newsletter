Perplexity AI has integrated the new GPT‑6 Astra model into its core operations, letting the AI handle everything from drafting communications to real‑time production monitoring.

## Perplexity trusts GPT-6 Astra with end-to-end systems

**What happened:** Perplexity now relies on the GPT‑6 Astra model—dubbed “Astra”—to write internal and external communications, modify software code, and continuously monitor production systems. The company reports that it needs to check the model’s outputs far less often than with previous generations.

**Why it matters:** By automating these critical tasks, Perplexity reduces human overhead, speeds up deployment cycles, and improves reliability of its services. The reduced supervision requirement signals growing confidence in LLM alignment and safety.

**Key stats:**
- Model: GPT‑6 Astra
- Check‑in frequency: up to 5× lower than with earlier models
- Areas covered: communications, code changes, production monitoring

## Cognition helps Devin test its own work with GPT‑6 Astra

**What happened:** OpenAI integrated the GPT‑6 Astra model into its Devin AI‑assistant. Astra gives Devin the ability to automatically generate and run tests on the code it writes, then verify the results without human intervention.

**Why it matters:** By automating verification, developers can reduce manual code reviews, catch bugs earlier, and accelerate product releases. The self‑testing loop also showcases how increasingly capable foundation models can handle end‑to‑end development tasks.

**Key stats:**
- Test coverage on Devin‑generated code rose from ~45% to >85% after Astra’s integration.
- Engineers reported a 30% drop in time spent on code review.
- Deployment cycles shortened by roughly 20%, enabling faster feature rollout.

## Build more natural voice experiences with GPT‑Live‑1 in the API

**What happened:** OpenAI released GPT‑Live‑1, a new model that supports natural, full‑duplex voice conversations directly via the API. It includes improved instruction compliance, the ability to create custom voice personas, and built‑in telephony support.

**Why it matters:** Developers can now build truly conversational AI experiences—like real‑time phone assistants or interactive voice bots—without stitching together separate speech‑to‑text and text‑to‑speech services. The tighter integration reduces latency and simplifies deployment.

**Key stats:**
- Full‑duplex (simultaneous speaking and listening) enabled out‑of‑the‑box.
- Custom voice generation allows branding and accessibility tweaks.
- Telephony support means direct call handling via the API.
