## Progressive Skill Discovery as Access Control for Tool-Using LLM Agents: Structural Governance through Role-Scoped Capability Delivery

**What happened:** A team introduced a structural governance approach that delivers capabilities to large language model (LLM) agents through role‑scoped skill discovery, rather than exposing every internal tool at once.

**Why it matters:** Unrestricted tool access inflates context windows, hampers tool selection, and creates governance gaps because prompt‑based policies are probabilistic, not enforceable. By limiting agents to needed skills, enterprises can improve safety, auditability, and performance.

**Key stats:** The paper highlights qualitative risks—oversized context windows and degraded tool selection—but does not provide quantitative metrics at this stage.

**Source:** https://arxiv.org/abs/2609.28693

## Forecast-Dojo: Replayable Environments for Benchmarking and Training LLM Forecasting Agents

**What happened:**
The team behind Forecast-Dojo released a replayable environment that blends resolved prediction‑market questions with time‑stamped news articles. Agents can research an event, make a forecast, and then revisit their prediction as the timeline advances, all within the same dataset.

**Why it matters:**
This platform removes the wait for future events to resolve, enabling rapid iteration, consistent benchmarking, and the collection of training data for LLMs tasked with forecasting. It promises faster progress toward trustworthy, time‑aware AI assistants.

**Key stats:**
- Built on thousands of historically resolved prediction‑market questions.
- Includes curated news snapshots for each historical date.
- Supports repeated evaluation cycles without new real‑world outcomes.
- Designed for both benchmarking and fine‑tuning LLM forecasting agents.

**Source:** https://arxiv.org/abs/2609.28876

## Control the Harness, Control the Cost: Routing and Governing AI Coding Agents in the Enterprise

**What happened:** AI coding agents are being deployed at massive scale. What began as pilot programs with a few hundred seats is now expanding to tens of thousands of users across companies. Most firms purchase the underlying "harnesses"—the platforms that run the agents—from large providers such as Anthropic’s Claude Code or OpenAI’s Codex.

**Why it matters:** A harness determines which model responds, what data it can read, how prompt caching is managed, and which sub‑agents are invoked. Without clear routing and governance, enterprises risk runaway costs, data leakage, and unpredictable behavior in mission‑critical code generation.

**Key stats:** • Pilot deployments: ~100‑500 seats → Enterprise roll‑outs: 10,000+ seats
• Majority of firms source harnesses from top‑tier vendors rather than building in‑house
• Governance decisions (model selection, cache policy, sub‑agent orchestration) directly impact spend and compliance risk

**Source:** https://arxiv.org/abs/2609.28919

## PFArena: Benchmarking Language Models for Protein Modification

**What happened:** Researchers released PFArena, a comprehensive benchmark that simulates realistic experimental decision‑making for protein modification and pits PLMs, LLMs, and LLM‑based agents against each other.
**Why it matters:** Protein engineering faces a massive sequence space and costly wet‑lab validation; a clear performance yardstick helps prioritize computational approaches that can cut time and expense.
**Key stats:** • Introduces a suite of realistic protein‑modification scenarios
• Evaluates multiple model families (PLMs, LLMs, agent‑based systems) on a shared leaderboard
• Provides public datasets and metrics to standardize future research
**Source:** https://arxiv.org/abs/2609.28921

## AlphaDiverse: Post-Training Local Quantitative Research Agents for Diverse Exploration in Alpha Factor Mining

**What happened:** The team introduced AlphaDiverse, a post‑training, locally‑run multi‑agent system designed to harvest alpha factors while deliberately widening research paths. By keeping the agents on‑premise, the framework sidesteps the typical reliance on external API calls.
**Why it matters:** Reducing API dependence lowers costs, safeguards confidential data, and prevents research loops from converging on a narrow set of mechanisms—an issue that has hampered prior multi‑agent alpha‑mining efforts.
**Key stats:** In their evaluation, AlphaDiverse generated significantly more distinct research trajectories and cut external API usage by a sizable margin, demonstrating both higher exploration diversity and lower operational overhead (see paper for exact figures).
**Source:** https://arxiv.org/abs/2609.29014
