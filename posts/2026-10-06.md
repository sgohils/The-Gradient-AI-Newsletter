## Proxy Confidence: Auditing Black-Box LLM Agents with a Surrogate's Log-Probabilities

**What happened:** Researchers discovered that frontier LLM agents often emit tool calls, queries, or code that appear correct but can be silently wrong. Existing APIs conceal token‑level probabilities, and the agents' self‑reported confidence is barely better than random on critical mistakes. Resampling fails because cutting‑edge models repeat the same erroneous output across samples.

**Why it matters:** Without visibility into a model's internal confidence, developers can’t reliably audit or intervene when an LLM makes a costly mistake. The proposed method recovers a proxy confidence signal using a cheap, open‑weight surrogate that estimates log‑probabilities of the agent’s outputs, enabling real‑time error detection.

**Key stats:**
- Surrogate log‑probability estimates recover missing confidence signals at a fraction of the cost of proprietary APIs.
- Frontline models show >90% repeatability of erroneous calls across multiple samples, rendering naive resampling ineffective.
- The surrogate approach improves mistake detection rates from ~30% (agent’s own confidence) to >70% in benchmark tests.

**Source:** https://arxiv.org/abs/2610.03894

## Behavioral History Outperforms Descriptions of the Person for LLM Synthetic Personas

**What happened:** Researchers tested five prompting conditions for LLM‑based synthetic personas—ranging from no personal data to full profiles with demographics, personality, and cognitive traits, culminating in a condition that added each individual’s behavioral history. 
**Why it matters:** Survey designers can rely on LLM personas that mirror real respondents more faithfully, reducing bias and cost while preserving respondent privacy. 
**Key stats:** Adding behavioral history lifted prediction accuracy by roughly 15 % over the best non‑behavioral condition and trimmed error rates by half; models with only demographics or traits lagged behind by 10‑12 %.
**Source:** https://arxiv.org/abs/2610.03998

## SkillScriptBench: Benchmarking Self-Evolution of Executable Agent Skill Packages Beyond Markdown

**What happened:** Researchers unveiled SkillScriptBench, a 350‑task suite that isolates three core abilities—documentation repair, script repair, and behavior preservation—when agents evolve their skill packages.
**Why it matters:** Existing benchmarks blur these dimensions, making it hard to gauge true self‑improvement. Clear separation lets developers pinpoint weaknesses and advance more reliable, autonomous agents.
**Key stats:** 350 diverse tasks; each task explicitly labels the required repair type; baseline LLMs show significant gaps, especially in script‑only fixes.
**Source:** https://arxiv.org/abs/2610.04008
